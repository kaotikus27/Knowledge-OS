# Product

## Purpose

A portable operating system for durable knowledge, projects, and active work.

## Primary User

Leo, working as Software Engineer (Angular / Spring Boot).

## Success

- Capture is frictionless.
- Active work is easy to locate.
- Durable knowledge stays distinct from temporary execution state.
- AI agents receive only relevant, privacy-safe context.
- The system remains portable, maintainable, and reversible.

## Non-Goals

- Replacing source-of-truth business applications.
- Storing secrets.
- Automatically granting AI access.
- Loading the entire vault for routine tasks.
